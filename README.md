# HA Wine Cellar
Home Assistant add-on: a filterable wine cellar app (add / drink / remove bottles, check-ins, drink-soon, charts) backed by Postgres. See `wine_cellar/DOCS.md`.

Features: barcode scanning, label photo reading, pictures, printable wine list, edit table, stats, CSV export/import, Grafana views. Racks with drag and drop are built but switched off (`docs/`).

Install: Settings → Add-ons → Add-on store → ⋮ → Repositories → add this repo's URL. While the repo is private, copy the `wine_cellar` folder into `/local_apps` instead.
